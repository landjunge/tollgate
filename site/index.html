Built for real agents

Works with your stack

Use Tollgate without rewriting your application. Point the SDK at a new base URL — protection is on the wire.

OpenAI Anthropic MCP n8n
python · drop-in 
# OpenAI-compatible — no app rewrite
from openai import OpenAI

client = OpenAI(
    base_url="http://127.0.0.1:8787/v1",
    api_key="support-agent",  # or id:secret
)

client.chat.completions.create(
    model="tollgate/free",
    messages=[{"role": "user", "content": "hi"}],
    extra_body={"tool_calls_est": 3},
)
