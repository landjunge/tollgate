Three pillars

Protect · Route · Prove

LiteLLM connects models. Helicone shows traffic. Tollgate keeps agents in line — and proves failover works.

🛑

Protect

Hard stops before the network call. Budgets, tool-loop depth, scopes, freeze, audit.

  • max_tool_calls — loop hard deny
  • $ / request / hour / day envelopes
  • Allow/block providers · intents · ops
  • tollgate freeze kill switch
🔀

Route

Health-aware routing when the primary dies at 3am. Circuits + failover, not vibes.

  • Intent routing (free_llm, llm, …)
  • Circuit breakers per provider
  • OpenAI & Anthropic drop-ins
  • n8n · MCP · OpenAI SDK
✅

Prove

Chaos tests, resilience score, certificate scorecard — evidence for ops and stakeholders.

  • tollgate chaos test
  • Resilience score 0–100
  • AI Reliability certificate
  • Control Room dashboard

Get started

10 minutes to protected

Python ≥ 3.11. Protect demo works without provider keys.

Install & run the cold path

./scripts/ten-minute.sh — Protect → Prove → certificate

Open Control Room

http://127.0.0.1:8787/dashboard — Setup wizard for the first agent

Point your agent at Tollgate

OPENAI_BASE_URL=http://127.0.0.1:8787/v1 · key = lane label or id:secret

Set envelopes

tollgate consumer-budget support-agent --max-usd-day 2 --max-tool-calls 20

everyday 
export OPENAI_BASE_URL=http://127.0.0.1:8787/v1
export OPENAI_API_KEY=support-agent

tollgate status
tollgate certificate --application "Support Agent"
tollgate freeze --reason "incident"
tollgate help
tollgate help protect

Docker: docker compose up -d --build
